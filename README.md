# Universal Mod Manager

I like r2modman, but sometimes I need to patch a game that's not supported, and I want to keep my game folders clean and my mods available in case I uninstall and reinstall a game. So I talked to my friend Claude about it and ended up with this 100% vibecoded slopware that does just that.

UMM copies mod files to game folders, checks for conflicts, lets you toggle mods on or off, and lets you revert deployed mod files manually in case your system crashes mid-session. It's also written in Rust so no one can hack your computer while you do it!
